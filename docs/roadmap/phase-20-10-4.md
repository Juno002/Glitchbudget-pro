## Local-only y ausencia de red

`npm run check:local` rechaza primitivas de red, endpoints de servidor, URLs remotas, SDKs remotos y builds no estáticos.

El E2E registra requests y falla si aparece una petición HTTP(S) a un origen distinto del de la propia app.

El build falla si cualquier HTML exportado no contiene exactamente:

```text
connect-src 'none'
```

## Categorías default

20.10.4 añade una regresión explícita sin cambiar producto:

- los seeds canónicos de gasto, ingreso y `otros` deben estar activos en una base nueva;
- nombres, iconos y scopes deben coincidir con `categorySeeds`;
- los órdenes visibles deben coincidir con el orden canónico;
- `GlitchBudgetDB` debe poblar `categories` mediante `reconstructCategories({})`.
